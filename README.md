# MeetingAI PWA

Prototype gratuit installable depuis Safari après publication HTTPS.

## Fonctionnalités
- Enregistrement audio et import de fichiers
- Bibliothèque de réunions dans IndexedDB
- Édition de transcriptions et comptes rendus
- Export audio et texte
- Cache de l'interface hors ligne

## Limitations
- Pas de transcription automatique Whisper, de diarisation ni de LLM intégrés dans cette version.
- Enregistrement écran verrouillé non garanti sur Safari iOS.
- Les données locales peuvent être effacées par iOS ; exporter les enregistrements importants.
- Aucune validation sur iPhone réel effectuée.

## GitHub Pages
Rendre le dépôt public puis Settings > Pages > Deploy from a branch > main / (root).
